# Next.js Portfolio

A personal portfolio website built as a learning project to explore Next.js and Tailwind CSS. Not currently deployed.

## Tech Stack

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
